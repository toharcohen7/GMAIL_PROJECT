# Android App Features Guide

This document provides an overview of the key features in the Gmail Project Android application and how to use them effectively.

## Email Management

### Viewing Emails

- **Inbox View**: Access your received emails from the "Received" label in the navigation drawer
- **Email Preview**: Tap on any email to open it and view its complete content
- **Email Details**: View sender information, subject, content, and timestamp
- **Email Indicators**:
  - Bold text indicates unread emails
  - Star icon indicates starred emails
- **Automatic Read Marking**: Emails are automatically marked as read when opened

### Composing and Sending Emails

- **New Email**: Tap the floating action button (FAB) to compose a new email
- **Recipients**: Enter recipient usernames separated by commas
- **Subject & Content**: Add your email subject and message content
- **Send**: Tap "Send" button to deliver your email
- **Draft**: Tap "Cancel" to save as draft (will be saved if any field contains content)

### Draft Management

- **Accessing Drafts**: Select the "Draft" label from the navigation drawer
- **Continuing Drafts**: Tap on any draft to resume editing
- **Sending Drafts**: Complete your draft and tap "Send" to deliver it
- **Empty Drafts**: Drafts with no content will be automatically deleted

### Email Organization

- **Moving Emails**: 
  1. Select one or more emails
  2. Tap the folder icon
  3. Choose destination label
- **Starring Emails**: Tap the star icon next to any email to mark it as important
- **Viewing Starred**: Select "Starred" in navigation drawer to see all starred emails

## Label Management

### Using Labels

- **System Labels**: Access inbox, sent, draft, spam, and trash from the navigation drawer
- **Custom Labels**: Create your own labels for better organization

### Creating Labels

1. In the navigation drawer, tap the "+" icon next to "Labels"
2. Enter a name for your new label
3. Tap "Add" to create the label

### Editing and Deleting Labels

- **Edit Label**:
  1. Long-press on a custom label in the navigation drawer
  2. Select "Edit" from the options
  3. Enter a new name
  4. Tap "Save"

- **Delete Label**:
  1. Long-press on a custom label in the navigation drawer
  2. Select "Delete" from the options
  3. Confirm deletion

## Bulk Actions

Select multiple emails by long-pressing on one email, then tapping others to perform:

- **Mark as Read/Unread**: Tap envelope icon
- **Star/Unstar**: Tap star icon
- **Delete**: Tap trash icon (moves to trash label)
- **Move**: Tap folder icon and select destination
- **Mark as Spam**: Tap shield with X icon

## Search Functionality

1. Tap the search icon in the app bar
2. Enter your search query
3. Results update as you type
4. Search examines sender name, subject, and email content
5. Pull down to refresh results or clear search to return to current label

## Spam Protection

### Managing Spam

- **Marking as Spam**: 
  1. Select one or more emails
  2. Tap the shield with X icon
  3. URLs in these emails are automatically extracted and blacklisted

- **Removing from Spam**:
  1. Navigate to the Spam label
  2. Select the emails to recover
  3. Tap the shield with check icon
  4. Emails will be moved back to the inbox
  5. URLs in these emails are removed from the blacklist

## Account Management

### Profile Information

1. Tap your profile picture in the app bar
2. View your profile details:
   - Username and full name
   - Gender and birth date
   - Profile picture
3. Tap "Close" to return

### Signing Out

1. Tap the three dots menu in the top-right corner
2. Select "Sign Out"
3. You'll be redirected to the sign-in screen

## Interface Personalization

### Dark Mode / Light Mode

1. Tap the three dots menu in the top-right corner
2. Select the dark/light mode toggle
3. The interface will immediately update
4. Your preference is remembered between sessions

### Refresh and Sync

- **Pull to Refresh**: Pull down on the email list to sync with the server
- **Automatic Updates**: The app automatically refreshes when changing labels

## Offline Access

- **Cached Emails**: Previously loaded emails are available offline
- **Offline Drafts**: Create and edit drafts without internet connection
- **Sync on Reconnect**: Changes sync automatically when connection is restored
