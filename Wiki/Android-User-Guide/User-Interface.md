# Android App User Interface Guide

This document provides a comprehensive overview of the Gmail Project Android app's user interface, helping you navigate and understand the app's layout and design elements.

## Main Interface Components

The Gmail Project Android app interface is designed with material design principles and consists of several key components:

### Home Screen

The home screen is the primary interface you'll interact with and includes:

1. **App Bar**: Contains the app title, search icon, and user profile
2. **Search Bar**: Quick access to search functionality
3. **Navigation Drawer Icon**: Access to folders and app menu (☰)
4. **Email List**: Displays emails in the current label/folder
5. **Floating Action Button (FAB)**: Compose new email button
6. **Bulk Action Bar**: Appears when selecting multiple emails

### Navigation Drawer

Access the navigation drawer by swiping from the left edge or tapping the menu icon (☰).

The navigation drawer contains:

1. **System Labels**:
   - Inbox (Received)
   - Sent
   - Draft
   - Spam
   - Trash
   - Starred (special view for starred emails)

2. **Custom Labels Section**:
   - User-created labels with icon indicators
   - Long-press on custom labels for edit/delete options
   - Add new label option (+ icon)

### Email List View

The email list displays:

1. **Selection Checkbox**: For selecting multiple emails
2. **Sender Name**: Name of the email sender
3. **Subject Line**: Email subject with preview text
4. **Timestamp**: When the email was received
5. **Star Icon**: Indicates starred status
6. **Visual Indicators**:
   - Bold text: Unread emails
   - Regular text: Read emails

### Email Detail View

When viewing an individual email:

1. **Top Bar**:
   - Back button
   - Email actions (star, delete, etc.)

2. **Email Header**:
   - Sender details
   - Recipients information
   - Subject
   - Timestamp

3. **Email Body**:
   - Message content

4. **Action Options**:
   - Reply
   - Forward
   - Mark as unread
   - Move to label

## Navigation Patterns

### Menu Options

The top-right menu provides access to:

1. **User Profile**: View your account information
2. **Dark/Light Mode Toggle**: Switch between display themes
3. **Sign Out**: Log out of your account

### Bulk Actions

When selecting multiple emails:

1. **Mark as Read/Unread**: Open/closed envelope icons
2. **Star/Unstar**: Star icon
3. **Move to Label**: Folder icon
4. **Delete**: Trash icon
5. **Mark as Spam**: Shield icon with X

## Email Management

### Viewing Emails

1. Click on any email in the list to open and view its contents
2. Emails are automatically marked as read when opened
3. Use the back button to return to the email list

### Managing Emails

1. **Mark as Read/Unread**:
   - Select email(s) and tap the envelope icon
   - Visual indicator (bold text) shows unread status

2. **Star Important Emails**:
   - Tap the star icon next to an email
   - View starred emails by selecting "Starred" in the navigation drawer

3. **Delete Emails**:
   - Select email(s) and tap the trash icon
   - Deleted emails are moved to the Trash label

4. **Spam Management**:
   - Mark as spam: Select email(s) and tap the shield with X icon
   - Remove from spam: Open the Spam folder, select email(s), tap the shield with check icon

### Moving Emails Between Labels

1. Select one or more emails
2. Tap the folder icon in the bulk action bar
3. Choose the destination label from the dialog
4. The emails will be moved to that label

## Composing Emails

1. Tap the floating action button (FAB) to compose a new email
2. In the compose dialog:
   - Enter recipient usernames separated by commas
   - Enter a subject
   - Write your message
   - Tap "Send" to send immediately or "Cancel" to save as draft

### Managing Drafts

1. Drafts are automatically saved when you cancel composition
2. Access your drafts by selecting the "Draft" label
3. Tap on a draft to continue editing
4. When ready, tap "Send" to send the email

## Label Management

### Creating New Labels

1. In the navigation drawer, tap the "+" icon next to Labels
2. Enter a name for your new label
3. Tap "Add" to create the label

### Editing Labels

1. Long-press on a custom label in the navigation drawer
2. Select "Edit" from the options
3. Enter a new name for the label
4. Tap "Save" to update the label

### Deleting Labels

1. Long-press on a custom label in the navigation drawer
2. Select "Delete" from the options
3. Confirm deletion when prompted

## Search Functionality

1. Tap the search icon in the app bar
2. Enter your search terms
3. Results will display emails matching your search criteria
4. The search looks for matches in sender name, subject, and content

## Dark/Light Mode

1. Access the menu by tapping the three dots in the top-right corner
2. Select the dark/light mode toggle option
3. The app interface will immediately switch between dark and light themes
4. Your preference is remembered between sessions

## Profile Information

1. Tap your profile icon in the app bar or select "User Profile" from the menu
2. View your profile information:
   - Username
   - Full name
   - Gender
   - Birth date
   - Profile picture
3. Tap "Close" to return to the main interface
