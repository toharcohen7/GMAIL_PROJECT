# Getting Started with the Gmail Project

Welcome to the Gmail Project! This guide will help you get started with using our email application.

## Account Setup

### Creating a New Account

1. Navigate to the Welcome Page (`http://localhost:3000`)
2. Click the "Create a User" button
3. Fill in your details on the Sign Up form:
   - User Name (unique identifier)
   - Password (and confirm password)
   - First Name
   - Last Name
   - Gender (select from dropdown)
   - Birth Date
   - Profile Image (optional)
4. Click "Sign Up" to create your account
5. After successful registration, you'll be redirected to the Sign In page

### Signing In

1. Navigate to the Welcome Page (`http://localhost:3000`) 
2. Click the "Sign In" button
3. Enter your credentials:
   - User Name
   - Password
4. Click "Sign In"
5. Upon successful authentication, you'll be redirected to your inbox

## User Interface Overview

### Main Interface Components

The interface is organized into several key areas:

1. **Top Bar**: Contains the compose button, search bar, and user profile
2. **Sidebar**: Access system labels and custom labels
3. **Email List**: View emails in the currently selected label
4. **Email Preview**: Read the selected email content
5. **Action Buttons**: Mark as read/unread, delete, move to label, etc.

### Light/Dark Mode

1. Click the moon/sun icon in the top bar to toggle between light and dark mode
2. The interface will immediately update to reflect your preference

## Basic Email Operations

### Composing a New Email

1. Click the "Compose" button in the top bar
2. In the compose form that appears:
   - Enter recipient usernames in the "To" field (separated by commas)
   - Enter a subject
   - Write your message in the main text area
3. Click "Send" when ready

### Reading Emails

1. Select a label from the sidebar (Inbox, Sent, etc.)
2. Click on an email in the email list to view its contents
3. The email will be automatically marked as read

### Managing Drafts

1. If you close the compose form before sending, your email is saved as a draft
2. Access your drafts by clicking on the "Draft" label in the sidebar
3. Click on a draft to continue editing
4. When ready, click "Send" to send the email

## Email Management

### Marking Emails

1. Select one or more emails by checking the boxes next to them
2. Use the toolbar buttons to:
   - Mark as read/unread (envelope icons)
   - Star/unstar (star icon)
   - Delete (trash icon)
   - Move to another label (folder icon)

### Deleting Emails

1. Select one or more emails
2. Click the "Delete" (trash icon) button
3. The emails will be moved to the Trash label
4. To permanently delete, go to Trash label and delete again

## Search Functionality

To find specific emails:

1. Click in the search bar at the top of the page
2. Type your search term
3. Press Enter or click the search icon
4. Results matching your search will be displayed

## Spam Management

### Marking Emails as Spam

1. Select one or more emails
2. Click the "Mark as Spam" button (shield icon)
3. The emails will be moved to the Spam label
4. URLs in these emails will automatically be added to the blacklist

### Removing Emails from Spam

1. Go to the Spam label
2. Select the email(s) you want to mark as not spam
3. Click the "Not Spam" button
4. The emails will be moved back to the inbox
5. URLs in these emails will be removed from the blacklist
